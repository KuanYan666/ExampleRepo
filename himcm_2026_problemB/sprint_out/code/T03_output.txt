3) Worked example: one 2.5 m freezer case under the US and EU metrics
==============================================================================
TDA = 3.25 m2 = 35.0 ft2 (assumed Dh = 1.3 m)
US DOE limit, open (VOP.RC.L):   83.8 kWh/day  = 25.8 kWh/day per m2
US DOE limit, glass door (VCT.RC.L):  19.8 kWh/day  =  6.1 kWh/day per m2
  -> DOE lets an open freezer use 4.2x a doored one of the same TDA
EU reference SAE/365 for ANY vertical freezer cabinet, open or doored:  70.2 kWh/day
  EU ecodesign cap from 1 Sep 2023: EEI <= 80 %  ->  E_daily <=  56.2 kWh/day
  a case measuring 40 kWh/day -> EEI  57.0 %  label class E
  a case measuring 60 kWh/day -> EEI  85.4 %  label class G
  a case measuring 80 kWh/day -> EEI 113.9 %  label class G
Team case 2.5 kW load, dew -30 C: AHRI EER 6.41 -> CEC 30.6 kWh/day (compressor only)
   same case, ISO 23953 REC with T0 = -30 C: 45.2 kWh/day
Team case 2.5 kW load, dew -35 C: AHRI EER 5.64 -> CEC 34.8 kWh/day (compressor only)
   same case, ISO 23953 REC with T0 = -35 C: 49.7 kWh/day

fans    open   5.69  doored   4.58 kWh/day
ash     open   0.00  doored  15.50 kWh/day
total   open  53.07  doored  43.71 kWh/day -> saving 17.6% ; compressor saving 72.3%
